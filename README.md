## 伦敦 200ms 是什么水平，什么场景该退一步

能用，但要看用途。200ms 意味着一次请求往返五分之一秒，网页首屏、SSH 敲命令、看视频都感知得到，不影响正常使用；FPS 游戏、实时行情这类场景不要选它。

CN2 GIA 的价值在晚高峰的稳定性，不在把绝对延迟压下来。普通 163 线路的欧洲 VPS 白天也能跑 200ms 上下，一到晚上八九点 ping 值翻倍、丢包上来才是问题。GIA 回程解决的是这一段。

三个机房的延迟差距很直观：

| 机房 | 到国内延迟（第三方测评口径） | 适合的场景 |
| --- | --- | --- |
| 美国圣何塞 | 约 168ms | 访客主要在国内，建站、代理、流媒体 |
| 德国法兰克福 | 约 180ms | 欧洲业务，需要欧洲 IP |
| 英国伦敦 | 约 200ms | 需要英国 IP、英区内容、覆盖欧洲西部 |

这组数字来自测评作者的体感记录，不是官方 SLA，你本地三网的实际值会不一样。

英国是三者里最慢的，多出来的 30ms 换来的是一个英国 IP。如果你没有明确的地域需求，圣何塞的 168ms 更划算，套餐选择也更多；法兰克福同样 299 元起，适合对接欧洲客户。伦敦机房存在的意义就是那批"必须落在英国"的需求——英国公司主体、英区流媒体、面向英国本地用户的服务。为了这 30ms 纠结没有意义，为了一个英国 IP 多付这 30ms 才有意义。

线路口径补充一句：官方宣传的是三网回程 CN2 GIA，电信、联通回程走 GIA 比较明确；移动去程各家测评说法不一，有写 CMIN2 的，也有写直连的。你如果主要用移动网络，先测再买。

- **流量用完只能等账单日次日重置**，不能提前重置，也没有临时加购流量的通道。
- **月付想改季付或年付**，需要把对应金额充值到余额后提交工单，不能补差价升级。
- 工单在工作时间内承诺 24 小时答复、48 小时解决。
